    Supply¶

    The Supply API tells you which vessels are available for a market segment, and how many. It has daily history since 2014 and a live view of today. You can filter on more than 150 fields: vessel class or size, open location and date, commercial status, voyage state, AIS position, custom ETAs to a port, and vessel particulars.

    You need your own API key with access to the Supply API. Your subscription also sets the vessel classes that you can query. A request for a vessel class that your key cannot access fails with an error (HTTP 403).

    Methods¶

    Method Use it for Dates
    get_supply_trend Vessel counts per day, for trends and charts A start date and an end date
    get_historical_supply The list of vessels on one past day One day
    get_live_supply The list of vessels now Always now

    All three methods take the same filters (SupplyFilter), a Baltic route template, or both. Each filter needs a vessel class (vessel_class), or a size band (vessel_type, defining_size and size together).

    Examples¶

    Supply trend with filters¶

    from datetime import date

from signal_ocean import Connection
from signal_ocean.supply import (
    CommercialAvailabilityFilter,
    FromToRange,
    GeoLocation,
    IncludeExcludeFilter,
    LocationTaxonomy,
    SupplyAPI,
    SupplyFilter,
    VesselClass,
)

api = SupplyAPI(Connection("YOUR_API_KEY"))

# Aframax tankers that open in Houston (port 3853) within 20 days,
# with commercial data updated in the last 5 days.
filters = SupplyFilter(
    vessel_class=VesselClass.AFRAMAX,
    commercial_availability=CommercialAvailabilityFilter(
        open_location=IncludeExcludeFilter(
            values=[GeoLocation(geo_id=3853, location_taxonomy=LocationTaxonomy.PORT)]
        ),
        open_date_relative_offset=FromToRange(from_=-5, to=20),
        latest_updated_date_relative_offset=FromToRange(from_=-5, to=0),
    ),
)

trend = api.get_supply_trend(date(2026, 10, 1), date(2026, 10, 31), filters=filters)
trend.to_data_frame()  # index: date, column: supply

    A Baltic route template with one change¶

    from signal_ocean.supply import MinMaxRange, VesselParticularsFilter

# TD3C, but with vessels up to 20 years old instead of 15.
# All other TD3C filters stay as they are.
trend = api.get_supply_trend(
    date(2026, 10, 1),
    date(2026, 10, 31),
    template="TD3C",
    filters=SupplyFilter(
        vessel_particulars=VesselParticularsFilter(vessel_age=MinMaxRange(max=20))
    ),
)

    Live supply as a data frame¶

    live = api.get_live_supply(template="TD25")
frame = live.to_data_frame()  # one row per vessel
frame[["imo", "open_location", "open_date_to", "eta_TD25"]]

    The Column class lists the column names. Each ETA configuration adds columns named after its id, for example eta_TD25 and eta_distance_TD25.

    How filters and templates combine¶

    • A filter field that you set replaces the template's value for that field as a whole. All other template filters stay. For example, vessel_age=MinMaxRange(min=5) replaces the template's age range, so the template's maximum age no longer applies. In the same way, open_location=IncludeExcludeFilter(values=[...]) also removes the template's excluded locations.
    • A list that you set replaces the template's list. It is not added to it.
    • Set a field to None to remove that template filter. None changes no other field.
    • vessel_class replaces the template's size band (vessel_type, defining_size and size), and a size band replaces the template's vessel_class.
    • An absolute date range, for example open_date, replaces the template's relative window for the same field.

    Good to know¶

    • Relative windows. A *_relative_offset range and eta_relative_offset count days from each snapshot day on get_supply_trend and get_historical_supply, and from today on get_live_supply. The templates use relative windows, so a template means the same on all three methods.
    • Commercial data history. Commercial availability history starts on 29 January 2026. For earlier days, the commercial filters and the ETA calculations use Signal's system-calculated values. Results before and after that day can look different.
    • Your organisation's data. From your account's start date, results show your organisation's own positions and commercial data. Before that date, results come from Signal's baseline data.
    • Hub ports on the trend. get_supply_trend always calculates ETAs to hub ports. An ETA basis port that is not a hub port is replaced by the hub port of its region, and the result's notes say so. So a trend count for an ETA template can differ a little from the live list of the same template. get_historical_supply uses the ports as given, unless you set use_only_hub_ports=True.
    • Daily limit on historical supply. Each API key can call get_historical_supply 5 times per day. For counts over a date range, use get_supply_trend.
    • HS4. Its name says 20 days, but its open window is 10 days. The SDK keeps the 10-day window of the template.
    • Errors. When the API refuses a request, the SDK raises requests.HTTPError. The error message includes the API's explanation, for example which filter is not valid.

    class SupplyAPI:
    """Retrieves vessel supply: daily counts, one day's vessels, live."""

    relative_url = "supply-api/v1/supply/"

    def __init__(self, connection: Optional[Connection] = None):
        """Initializes the Supply API.

        Args:
            connection: API connection configuration. If not provided, the
                default connection method is used.
        """
        self.__connection = connection or Connection()

    def get_supply_trend(
        self,
        start_date: date,
        end_date: date,
        template: Optional[str] = None,
        filters: Optional[SupplyFilter] = None,
    ) -> SupplyTrend:
        """Count the vessels that match the filters on each day of a range.

        Args:
            start_date: First day of the range.
            end_date: Last day of the range.
            template: A Baltic route code, for example `TD3C`. See
                `get_supply_templates`.
            filters: Filters. A field set here replaces the template's
                value for that field.

        Returns:
            One count per day, and the API's notes.
        """
        body = {
            "startDate": start_date.isoformat(),
            "endDate": end_date.isoformat(),
            **_filter_body(template, filters),
        }
        data = self.__post("supply-trend", body)
        return SupplyTrend.model_validate(data)

    def get_historical_supply(
        self,
        day: date,
        template: Optional[str] = None,
        filters: Optional[SupplyFilter] = None,
        use_only_hub_ports: Optional[bool] = None,
    ) -> SupplySnapshot:
        """Get the vessels that matched the filters on one past day.

        Each subscription key can make a limited number of these calls per
        day.

        Args:
            day: The snapshot day.
            template: A Baltic route code, for example `TD3C`.
            filters: Filters. A field set here replaces the template's
                value for that field.
            use_only_hub_ports: True remaps each ETA basis port that is not
                a hub port to the hub port of its region. False uses the
                ports as given. None sends nothing, so the API default
                (False) applies.

        Returns:
            One record per vessel.
        """
        body = {
            "startDate": day.isoformat(),
            "endDate": day.isoformat(),
            **_filter_body(template, filters),
        }
        headers = None
        if use_only_hub_ports is not None:
            headers = {"UseOnlyHubPorts": str(use_only_hub_ports).lower()}
        data = self.__post("historical-raw-data", body, headers)
        return SupplySnapshot.model_validate(data)

    def get_live_supply(
        self,
        template: Optional[str] = None,
        filters: Optional[Union[SupplyFilter, LiveSupplyFilter]] = None,
        include_details: bool = False,
    ) -> SupplySnapshot:
        """Get the vessels that match the filters now.

        Args:
            template: A Baltic route code, for example `TD3C`.
            filters: Filters. Use `LiveSupplyFilter` for ETA calculations
                with routing restrictions.
            include_details: True adds your company's notes to each record.

        Returns:
            One record per vessel.
        """
        body: Dict[str, Any] = dict(_filter_body(template, filters))
        if include_details:
            body["includeDetails"] = True
        data = self.__post("supply", body)
        snapshot = SupplySnapshot.model_validate(data)
        return snapshot.model_copy(update={"include_details": include_details})

    def get_supply_templates(self) -> Tuple[SupplyTemplate, ...]:
        """Get the Baltic route templates.

        Returns:
            The templates. Pass a template's `code` as `template`.
        """
        return get_supply_templates()

    def __post(
        self,
        operation: str,
        body: Dict[str, Any],
        headers: Optional[Dict[str, str]] = None,
    ) -> Any:
        response = self.__connection._make_post_request(
            self.relative_url + operation, body, headers=headers
        )
        _raise_for_status(response)
        return response.json()
