## New Features

Added new fields to the Scraped Positions API to expose ETA and basis port
information. Affected module and fields are:
- Scraped Positions API
    - ScrapedETA
    - ETA
    - ScrapedBasis
    - BasisGeoID
    - BasisName
    - BasisTaxonomyID
    - BasisTaxonomy

## Installation and Upgrade Notes

Update your package with: `pip install signal-ocean -U`
